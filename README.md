## 🌟 核心工程特色与交付价值

1. **工业物理事实与不可动摇的标准硬锚定**：
   - 全面执行 **ASTM D445、DIN 51524 Part 2/3 (HLP/HVLP)、ISO 11158 HM、Parker Denison HF-0、Cincinnati Lamb P-68/P-69/P-70**；
   - 每批次随附独立盖章的 **Certificate of Analysis (CoA)** 与 24 个月留样封签追溯机制；
   - 提供 ExxonMobil（DTE 25）、Shell（Tellus S2 M 46）、Fuchs（Renolin B 46）的 **1:1 精确等效物理替换表**。
2. **重液体危险品包装与 20GP 集装箱物流测算引擎**：
   - 采用 **UN 1A1/Y1.4/150** 认证冷轧重型钢桶（1.0-1.2mm 钢卷板，自重 18.5-19.5kg，全容积 208L）；
   - 内置 **20GP Container Loading Calculator**：精准计算 80 桶打托（16,640L / 16.44MT 净毛重平衡），完美符合全球各大港口公路限重；
   - 距厦门国际集装箱港仅 95 公里，FOB 出口订单 7-10 天极速备货放行。
3. **清爽无后缀 URL 全站路由与 SEO 权重聚合**：
   - 彻底告别 `.html` 廉价后缀，全站 70 个页面、`<a href>` 内部链接、`<link rel="canonical">`、Schema 及 `sitemap.xml` 100% 采用无后缀规范；
   - Nginx 配置强制 301 重定向与透明 `try_files` 解析，杜绝重复内容惩罚。
4. **出版级工业前端交互与动效体系**：
   - **CSS Grid 重叠堆叠 Hero 轮播**：3 Slides 共用单网格单元，彻底根治传统定位切换引起的重排（Reflow）与布局抖动（Zero Layout Shift）；
   - **视口下潜关键数字递增 (Dynamic Count-Up)**：滚动触发 2018 年创立、80 桶打托、100% 留样、35%-45% 成本优势从 0 飞速累加动效；
   - **两翼向心聚拢动效**：标题自左向中、卡片自右向中滑入，赋予精密机械般的仪式感；
   - **工业实景图点击无损放大画廊 (Lightbox)**：支持全屏无损放大查验钢桶焊缝、油样色泽及实验室仪器；
   - **侧边栏悬浮多渠道即时沟通枢纽**：高对比度悬浮 WhatsApp 预填草稿呼起与 WeChat 一键复制官方微信卡片。
5. **每日 3,000+ 字全自动深度能源研报与 3 天未来走势预测引擎**：
   - 内置 20 篇高深度历史开篇研报库；
   - 每日通过 Antigravity Automation 自动追踪宏观地缘、OPEC+ 配额、加氢二类/三类基油裂解价差；
   - 独创 **3-Day Predictive Forecast** 模型，每日量化预判未来 3 天基础油出厂价与液压油调价区间；
   - 自动更新 HTML、自动刷新新闻索引并同步追加至 `sitemap.xml`。
6. **Google Imagen 3 工业视觉生图规范**：
   - **100% 中国员工面孔约束**：化验师、中控工程师、叉车师傅、业务经理全量替换为真实中国专业团队；
   - **双轨中英官方品牌标识规范**：所有设备、储罐、钢桶及标牌统一标注：上面英文 `FOSS LUBRICATION`、下面中文 `福斯润滑`。
7. **多语言全球化矩阵与防幻觉摩擦学词库 (ES/RU/AR RTL/VI/ID)**：
   - 全面覆盖 **西班牙语 (`/es/`)、俄语 (`/ru/`)、阿拉伯语 (`/ar/` 支持全站 RTL 从右至左排版)、越南语 (`/vi/`)、印尼语 (`/id/`)**；
   - 严格挂载 `references/tribology-multilingual-dictionary.md` 6 语种摩擦学权威词库，彻底杜绝 AI 直译与行话幻觉；
   - 全站每个页面与 `sitemap.xml` 均配备完整的 6 语种 `hreflang` 国际互引标签。
8. **导航栏瘦身改造与多语言切换器 (Header Logo & Lang Switcher)**：
   - 去除了原 Logo 旁冗长的公司长文本，**仅保留纯净高清的官方 Logo 图标**，极大释放导航空间；
   - 在 Header 右侧无缝嵌入多语言下拉切换器，带国旗图标与双字母代码，各页面路径 1:1 无损互跳。
9. **询盘表单 100% 投递与 Cloudflare 防垃圾机制**：
   - 官方直收邮箱：`sales@fosslubricants.com`；
   - 域名级 SPF、DKIM、DMARC 邮件鉴权，彻底杜绝进垃圾箱；
   - 接入 Cloudflare Turnstile 静默无感人机验证，0 毫秒放行真人采购商，彻底拦截垃圾爬虫；
   - 邮件 + 飞书/企微 Webhook 双通道实时告警。
10. **云端生产部署与 CDN 缓存穿透策略**：
    - 自动化 Rsync 增量推送、自动权限复位（`www-data:www-data 755`）与 Nginx 平滑重载；
    - 图片资源附加版本号 `?v=20261010_v11`，彻底击穿 Cloudflare 30 天静态边缘缓存。
11. **Yandex SEO 与中亚（俄罗斯/哈萨克斯坦/乌兹别克斯坦）GEO 深度优化体系**：
    - 专为俄语区（市场份额近 70% 的 Yandex 搜索引擎）与 **Яндекс Нейро / Алиса AI** 生成式搜索深度定制；
    - **独联体与中亚专属出海超级门户 (`/ru/cis-central-asia`)**：针对哈萨克斯坦（矿业油气/抗低温 HVLP 46）、乌兹别克斯坦（冶金抗燃 HFC 4631 / 注塑机 HLP 46）、俄罗斯（数控机床与重载齿轮油 CKD 220/320）三大核心市场打造高转化落地页；
    - **中欧班列与铁路集装箱通道**：经霍尔果斯与阿拉山口/多斯特克口岸 10–14 天直达阿拉木图与塔什干，单柜 80 桶 208L（16,640 升 / 15.8 吨）；
    - **准入与标准对齐**：欧亚经济联盟 **ТР ТС 030/2012** 合规申报、Form ST-1 原产地证、全俄文 COA/MSDS 与完整的 **ГОСТ ↔ DIN ↔ ISO ↔ Mobil / Shell / Лукойл / ГПН** 1:1 替代矩阵；
    - **跨境人民币与非 SWIFT 结算**：支持中资银行 CNY 直清与 RUB 结算，彻底防范国际汇款冻结风险；

## 🛠️ 外贸出海建站 Skills 协同使用指南 (How to Use the Skills)

| 阶段 | 核心调用 Skill | 具体使用方式与触发 Prompt 范例 | 核心产出物 |
| :--- | :--- | :--- | :--- |
| **Step 1: 建立事实基底** | `product-truth-builder`<br>`exporter-profile-skill` | **触发 Prompt**：`为[企业名称]建立产品事实库，锁定成立年份、经纬度、反应釜容积、年产能、ASTM/DIN 标准公差与批次盖章 CoA 格式。` | 结构化产品事实库、Cross-Reference 对标替换表 |
| **Step 2: 工业视觉生图** | `antigravity-image-gen`<br>`brand-visual-director` | **触发 Prompt**：`生成 16:9 高清工业纪实摄影图，强制约束 100% 中国员工面孔，墙体设备双轨标牌：上面英文 FOSS LUBRICATION 下面中文 福斯润滑，负向锁定 caucasian, fake smiling。` | 10 张 16:9 工业纪实大图与 WebP 压缩资产 |
| **Step 3: 架构与路由** | `b2b-foss-lubricants-builder`<br>`b2b-global-brand-site-master` | **触发 Prompt**：`构建无后缀 URL 架构，生成 29 核心页面、Nginx 301 强制跳转与 try_files 配置，禁止使用 .html 内部链接。` | 无后缀 HTML 架构、`nginx.conf`、`sitemap.xml` |

| **Step 5: 每日研报自动化**| `automation`<br>`daily-news-automation-engine` | **运行命令**：`python3 scripts/generate_daily_news.py`。定时抓取国际原油走势，撰写 3000+ 字专业研报并推导 3 天走势预测。 | 自动化研报页面与动态 Sitemap 更新 |
| **Step 6: 多语言矩阵编译**| `b2b-foss-lubricants-builder`<br>`locale-market-adapter` | **运行命令**：`python3 scripts/build_multilingual_matrix.py`。挂载摩擦学词库编译 ES/RU/AR RTL/VI/ID 5 大国际子目录。 | 40 个国际子目录页面、`hreflang` 标签矩阵 |
| **Step 7: 部署与全量验证**| `scripts/validate_site.py`<br>`scripts/deploy_production.sh` | **运行命令**：`python3 scripts/validate_site.py . --release --domain https://www.fosslubricants.com && bash scripts/deploy_production.sh`。 | 70 个页面零错误通过、生产环境平滑生效 |

## 🚀 常用运行命令 (Quickstart CLI)

```bash
# 1. 运行多语言国际化矩阵编译 (生成 ES/RU/AR/VI/ID 5 大子目录与更新 Sitemap)
python3 scripts/build_multilingual_matrix.py

# 2. 运行每日研报自动化编译
python3 scripts/generate_daily_news.py

# 3. 全站 6 维静态完整性与 SEO 审计 (测试 70 个页面与 4889+ 内部引用)
python3 scripts/validate_site.py . --release --domain https://www.fosslubricants.com

# 4. 一键部署更新至生产服务器并刷新 Nginx
bash scripts/deploy_production.sh
```
