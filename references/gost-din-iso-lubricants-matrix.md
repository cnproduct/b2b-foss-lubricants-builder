# Матрица соответствия стандартов ГОСТ, DIN, ISO и импортозамещения масел FOSS

Настоящее руководство устанавливает технические соответствия между международными стандартами (ISO, DIN, ASTM), китайскими национальными стандартами (GB) и межгосударственными стандартами СНГ (ГОСТ), действующими на территории Российской Федерации, Республики Казахстан, Республики Узбекистан и стран ЕАЭС.

---

## 1. Соответствие Техническому Регламенту ЕАЭС

Все индустриальные масла и смазочные материалы FOSS соответствуют требованиям:
- **ТР ТС 030/2012** «О требованиях к смазочным материалам, маслам и специальным жидкостям» (Декларация о соответствии ЕАС).
- Паспорт безопасности химической продукции (MSDS / ПБХВ) по ГОСТ 30333-2007.
- Заводской сертификат качества / анализ партии (Certificate of Analysis — COA) с указанием фактических физико-химических показателей.

## 3. Таблица эквивалентности методов лабораторных испытаний (ГОСТ vs ASTM vs DIN)

При контроле качества каждой партии масел FOSS на заводе в Цюаньчжоу (КНР) оформляется Паспорт качества (COA). Ниже приведены нормативные соответствия методик испытаний:

| Контролируемый параметр | Международный метод (ASTM) | Метод DIN / ISO | Российский метод (ГОСТ) |
| :--- | :--- | :--- | :--- |
| **Кинематическая вязкость (40°C / 100°C)** | ASTM D445 | ISO 3104 / DIN 51562 | **ГОСТ 33-2016** (ГОСТ 33-2000) |
| **Индекс вязкости (VI)** | ASTM D2270 | ISO 2909 / DIN ISO 2909 | **ГОСТ 25371-2018** |
| **Температура вспышки в открытом тигле** | ASTM D92 (Cleveland) | ISO 2592 / DIN EN ISO 2592 | **ГОСТ 4333-2014** (ГОСТ 4333-87) |
| **Температура застывания (Pour Point)** | ASTM D97 / ASTM D5950 | ISO 3016 / DIN ISO 3016 | **ГОСТ 20287-91** (метод Б) |
| **Коррозия медной пластинки (3 ч при 100°C)** | ASTM D130 | ISO 2160 / DIN EN ISO 2160 | **ГОСТ 2917-76** (оценка: 1a / 1b) |
| **Деэмульгирующая способность (разделение с водой)** | ASTM D1401 | ISO 6614 / DIN ISO 6614 | **ГОСТ 12068-66** |
| **Воздухоотделение (Air Release)** | ASTM D3427 | ISO 9120 / DIN ISO 9120 | **ГОСТ Р 55877-2013** |
| **Класс промышленной чистоты жидкости** | ISO 4406 / NAS 1638 | ISO 4406:2021 | **ГОСТ 17216-2001** (чистота не ниже 9-10 класса) |
